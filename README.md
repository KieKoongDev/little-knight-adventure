# อัศวินจิ๋วผจญภัย v2.4.0

## ตัวละครและพื้น
- หน้าเลือกและในเกมใช้ตัวละครแบบเดียวกันทั้ง 10 ตัว รวมชุดและอาวุธเริ่มต้น
- สัดส่วนการ์ตูนกึ่งสมจริง หัวเล็กลง ลำตัวและขายาวขึ้น แขนมีข้อศอก และอาวุธยึดกับมือ
- ฟันแนวนอน ฟันเสย ฟันลง และฟันย้อน มีจังหวะเตรียม ฟัน และคืนท่า
- รักษาอัตราส่วนภาพ 16:9 เพื่อไม่ให้ตัวละครถูกยืดตามหน้าจอ
- พื้นหินมีมุมมองลึกและแนวขอบเฉพาะแต่ละฉาก ตัวละคร ศัตรู และไอเทมอยู่ในพื้นที่เดินเท่านั้น
- การกระโดดใช้ความสูงเหนือพื้น เงายังคงอยู่บนพื้น

## การต่อสู้และ co-op
- แก้ปุ่มบล็อกมือถือที่ถูกปลดโดยสถานะคีย์บอร์ด
- กัน + กระโดด หรือ Shift เพื่อหลบ มีช่วงอมตะสั้นและคูลดาวน์
- เพิ่มเวลารับคำสั่งคอมโบ และแบ่งการอัปเดตเฟรมเพื่อไม่ให้เกมช้าลงเมื่อเฟรมลดลง
- ลดการกระตุกเมื่อรับตำแหน่งเพื่อน และเพิ่มความถี่ข้อมูลผู้เล่น/โลก
- บอสมีสองเฟสและลำดับท่าต่างกัน: วงกระแทก แนวพุ่ง วงแหวน และท่าที่ช่วยกันตีขัดจังหวะได้
- วงฟ้าให้รวมกลุ่มเพื่อแบ่งความเสียหาย หรือหลบออก; ตั้งการ์ดได้
- หลังขัดจังหวะ บอสเสียหลักและรับความเสียหายเพิ่ม
- การโจมตีระยะประชิดและกระสุนศัตรูส่งถึงผู้เล่นอื่น ผู้เล่นแต่ละคนหลบและบล็อกบนเครื่องตัวเอง
- เจ้าห้องยังจำลองศัตรูได้ขณะล้ม และผู้ร่วมทีมได้รับการฟื้นฟูเมื่อเข้าสู่พื้นที่พัก
- ไอเทมใหม่จากศัตรูชั้นสูง/บอส: ระเบิดเพลิง ระเบิดเยือกแข็ง ชุดซ่อมเกราะ และเครื่องรางฟื้นฟูทีม

## เริ่มเล่น / Deploy
ใช้ `npm install` แล้ว `npm start` จากโฟลเดอร์นี้ เปิด http://localhost:8081

ZIP มีไฟล์วางที่ root โดยตรง ให้อัปโหลดไฟล์ทั้งหมดทับ root ของ repository เดิม รวมไฟล์ใหม่ `combat.js`, `ground.js`, `hero-renderer.js` และ `version-manifest.json` แล้ว deploy จาก main บน Railway เดิม ไม่ต้องสร้างโครงการใหม่

ตรวจ `/health` หลัง deploy ต้องตอบ `{"ok":true,"rooms":0,"version":"2.4.0"}` (จำนวน rooms อาจเปลี่ยนได้)

## การตรวจสอบ
ทดสอบบน Chrome ด้วยสองหน้าเว็บเชื่อม WebSocket จริง และจำลองหน้าจอมือถือแนวนอน ตรวจขอบพื้น การ์ด หลบ คำเตือนบอส การขัดจังหวะ ซ่อมเกราะ การหลบด้วยการกระโดด ความเสียหาย/ฮีลของผู้ร่วมทีม และการแทรกตำแหน่ง ไม่มี JavaScript runtime error ในรอบทดสอบ

หากต้องการรันทดสอบเอง: เปิดเซิร์ฟเวอร์ก่อน ติดตั้ง Playwright ด้วย `npm install --no-save --package-lock=false playwright@1.62.1` และมี Google Chrome จากนั้นรัน `node tests/browser.cjs`

การทดสอบครั้งนี้ยังไม่ใช่การเล่นระยะยาวบนโทรศัพท์จริงหรือเครือข่ายอินเทอร์เน็ตที่หน่วงสูง
