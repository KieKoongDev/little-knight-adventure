# อัศวินจิ๋วผจญภัย v2.3.0 — Dark Cinematic Combat

## ฉาก Generated
- 4 ฉากจากงาน image-generation แล้ว rebuild เป็น 1280×720 สำหรับ gameplay
- Dark Forest / Crimson Ruins / Frozen Cathedral / Dragon-fire Ruins
- มีพื้น perspective, fog, snow, embers, toxic haze และ cinematic vignette

## Combat
- ดาบกวัดแกว่งหลายมุม: horizontal / rising / overhead / reverse
- Block pose แน่นขึ้น เห็นแนวอาวุธและเกราะกันชัด
- ถือยา/ไอเทมแล้วเห็นของในมือ
- Enemy ragdoll: กระเด็น หมุน เด้งพื้น และไถล
- Armor (AR) สำหรับผู้เล่นและศัตรู
- Heavy / charge skill ทำลายเกราะได้มากขึ้น

## Status
- Burn: damage over time
- Freeze/Frost: แช่แข็ง + slow
- Poison: damage over time ระยะยาว
- Shock: stagger / chain
- Void: knock / control
- แสดงเอฟเฟกต์สถานะบนตัวศัตรู

## Charge Skill
กดปุ่ม Skill ค้าง แล้วปล่อย:
- Fire Pillar
- Ice Prison
- Poison Cloud
- Chain Lightning
- Void Rift

## Mobile
ปิด long-press text selection / copy / touch callout ในพื้นที่เกม

## Audio
เพิ่มระดับ music / drums / bass ให้หนักขึ้น
